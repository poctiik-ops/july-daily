# July Daily

Личный планер для iPhone: задачи по дням, редкие встречи со временем, цели на месяц и год, итоги недели. Стиль — Liquid Glass. Работает как PWA, без интернета, все данные хранятся на телефоне.

## Установка на iPhone

1. Открой сайт в **Safari**.
2. Нажми «Поделиться» → **«На экран „Домой“»** → «Добавить».
3. Запускай с иконки — приложение откроется на весь экран, без адресной строки.

## Что умеет

- **Календарь:** виды День / Неделя / Месяц / Год, листание свайпом.
- **Задачи и встречи:** задачи без времени, встречи со временем. Свайп вправо — выполнено, влево — удалить, долгое нажатие — перетащить.
- **Невыполненное:** в конце дня задача получает ✕, утром приложение предлагает перенести её на сегодня.
- **Повторы:** каждые N дней, любые дни недели, «N раз в неделю/месяц», числа месяца, «последняя пятница», ежегодно; окончание по дате или после N раз. Изменение «только этот / этот и следующие / все».
- **Категории** с цветом и иконкой.
- **Цели месяца и года:** прогресс по задачам, счётчик или отметка; перенос невыполненных на следующий период.
- **Помощник:** голосом или текстом, разбор фраз прямо на телефоне. Примеры:
  - «двенадцатого ноября в пятнадцать ноль ноль стоматолог»
  - «стоматолог 12 ноября с 15 до 17»
  - «каждый понедельник английский», «английский 3 раза в неделю»
  - «отмени стоматолога», «перенеси созвон на пятницу в 18:00»
  - «отметь растяжку», «что у меня завтра?»
- **Итоги** недели, месяца и года: статистика + анкета, вопросы редактируются.
- **Фон** меняется по времени суток (утром светлая тема, вечером тёмная), можно поставить своё фото.
- **Бэкап** в JSON-файл и восстановление.

## Устройство

Чистый HTML/CSS/JS без сборки, ES-модули, IndexedDB, service worker для офлайна.

```
index.html          оболочка
css/app.css         стили Liquid Glass
js/app.js           экраны, навигация, жесты
js/sheets.js        шторки: редакторы задач, повторов, целей, категорий, итоги
js/assist.js        помощник: голос, карточки подтверждения, команды
js/parser.js        разбор русских фраз (даты, время, повторы, команды)
js/store.js         данные, повторы, цели, статистика
js/util.js          даты, иконки, палитра
sw.js               офлайн-кэш и обновления
```

После изменений подними `VERSION` в `sw.js`, чтобы телефон подтянул новую версию (появится плашка «Обновить»).
